🧠 Entendendo o TEA

O que é o Transtorno do Espectro Autista?

O TEA é uma condição neurológica que afeta a forma como uma pessoa percebe o mundo e interage com as outras. Não é uma doença — é uma forma diferente e igualmente válida de existir.


✓
Cada pessoa com TEA é única
✓
Diagnóstico pode ocorrer em qualquer idade
✓
Apoio adequado faz toda a diferença
✓
Neurodiversidade é riqueza
